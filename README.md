# etus CLI

Binários da CLI `etus`, o terminal da plataforma Etus. O código fica num repositório privado; aqui ficam só as versões publicadas.

## Instalar

Pelo ETUS Platforms (recomendado): o hub mostra o comando de instalação com o endereço certo.

À mão: baixe em [Releases](https://github.com/evolution-foundation/etus-cli/releases/latest) o binário do seu sistema (`etus-aarch64-macos`, `etus-x86_64-macos`, `etus-x86_64-linux` ou `etus-aarch64-linux`), confira com o `SHA256SUMS`, dê permissão de execução e coloque no PATH.

## Atualizar

```bash
etus atualizar-cli
```
